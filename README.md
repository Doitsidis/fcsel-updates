# FC-SEL — δείκτης έκδοσης

Αυτό το repo είναι **δημόσιο σκόπιμα** και περιέχει ΜΟΝΟ έναν αριθμό
έκδοσης και σημειώσεις — όχι κώδικα, τιμές ή κατάλογο.

Το εργαλείο FC-SEL (ιδιωτικό repo: `Doitsidis/fcsel`) το διαβάζει αυτόματα
για να ειδοποιεί τους χρήστες ότι υπάρχει νεότερη έκδοση.
